# CHÁY CƠM - CƠM CHÁY VIỆT NAM (E-COMMERCE)

> **Slogan:** "Giòn rụm vị Việt - Cháy một miếng, nhớ cả quê"  
> **Phong cách:** WooCommerce Storefront E-Commerce Design System

Website thương mại điện tử chuyên cung cấp đặc sản cơm cháy ép chảo gia truyền, đượm vị mắm cá cơm Phú Quốc và ngập tràn chà bông heo tươi.

---

## 🌟 TÍNH NĂNG CHÍNH

- **Brand Identity:** Logo thương hiệu góc trên bên trái, hệ thống màu Vàng gạo (`#E8A838`), Nâu đậm (`#4A2810`), Kem (`#FFF8F0`), Trắng (`#FFFFFF`).
- **Typography:** Chuẩn WooCommerce Storefront (`Montserrat` & `Source Sans 3`).
- **5 Trang cốt lõi:**
  1. **Trang chủ (Home):** Hero banner, 3 cột USP, Sản phẩm bán chạy, Video âm thanh giòn rụm, Giới thiệu, Cam kết chất lượng, Đánh giá thực tế, Mạng xã hội, Chân trang.
  2. **Cửa hàng (Shop):** Lưới 6 sản phẩm, lọc theo danh mục, nhãn giảm giá, sao đánh giá.
  3. **Về chúng tôi (About Us):** Câu chuyện hạt gạo quê hương và 3 nguyên tắc chất lượng.
  4. **Chất lượng (Quality):** Tiêu chuẩn VSATTP, quy trình dầu mới 100%, bảo hành đổi trả 1-1.
  5. **Liên hệ (Contact):** Form liên hệ hoạt động, bản đồ, hotline 24/7.
- **Quy trình E-Commerce hoàn chỉnh:**
  - Sản phẩm Flagship có **Biến thể (Variants)**: Hộp 250g (65.000đ) & Túi Zip 500g (120.000đ).
  - Modal xem chi tiết sản phẩm (PDP) với bộ đếm số lượng và chọn quy cách.
  - Giỏ hàng trượt (Mini-Cart Drawer) + Trang Giỏ hàng (Cart Page) với mã ưu đãi `GIONRUM`.
  - Trang Thanh toán (Checkout Page) hỗ trợ phương thức **Thanh toán khi nhận hàng (COD)**.
  - Trang Cảm ơn (Order Confirmation) tự động tạo mã đơn hàng ngẫu nhiên.
  - Lưu trạng thái giỏ hàng tự động qua `localStorage`.

---

## 🚀 CÁCH CHẠY LOCAL

1. **Cách 1:** Click đúp trực tiếp vào file `index.html`.
2. **Cách 2:** Chạy file `run_local_server.bat` hoặc gõ lệnh:
   ```bash
   python -m http.server 8080
   ```
   Sau đó truy cập: `http://localhost:8080`
